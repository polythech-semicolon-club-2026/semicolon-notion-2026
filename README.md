# semicolon-notion-2026

세미콜론 동아리의 2026년 활동 아카이브입니다. 노션 HTML 내보내기를 바탕으로 독립 웹사이트로 제작했습니다.

## 바로 접속

[세미콜론 홈페이지 열기](https://polythech-semicolon-club-2026.github.io/semicolon-notion-2026/)

## 구성

- 노션 스타일 사이드바, 페이지 이동, 전체 검색, 목차, 최근 방문
- 작업·아이디어·회의·일정 및 대시보드에서 표·보드·갤러리·목록·캘린더 전환
- 상태·분류별 그룹과 필터, 이름·날짜 정렬, 항목 검색, 상세 페이지 이동
- 작업의 진행 상태는 내보낸 수행 예정자·수행 완료자를 비교해 구분
- 내보낸 본문·표·이미지와 첨부파일을 저장소에서 직접 제공
- 계정 관리 페이지, 관련 파일 및 대시보드의 계정 보기는 공개 배포에서 제외
- 달력·날씨·시계는 기존 외부 위젯을 연결

노션 원본을 삭제해도 저장된 본문과 로컬 이미지·첨부파일은 유지됩니다. 달력·날씨·시계와 외부 링크는 해당 외부 서비스에 의존합니다. 이 사이트는 읽기 전용 아카이브이며 노션의 편집·동기화 기능은 포함하지 않습니다.

## 배포

GitHub Pages가 `main` 브랜치의 루트(`/`)를 배포합니다. `index.html`이 홈페이지이고 `pages/`에 하위 페이지, `assets/`에 스타일·검색·이미지·첨부파일이 있습니다.

내보내기 기준: 2026-10-02. 노션 변경 사항은 자동 반영되지 않으며 새로운 내보내기로 갱신해야 합니다.
