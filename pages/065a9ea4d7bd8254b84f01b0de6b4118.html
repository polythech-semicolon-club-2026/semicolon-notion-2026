명령어 모음

Name기능사용 예시선택
git init현재 디렉토리를 로컬 저장소로 초기화 (.git 폴더 생성)git init초기화 및 설정
git clone원격 저장소의 전체 코드와 이력을 로컬로 복제git clone <클론할 레포짓토리 주소>초기화 및 설정
git config사용자 이름, 이메일 등 Git 환경 설정git config --global http://user.name/ "내이름"초기화 및 설정
git status워킹 트리 및 스테이징 영역의 현재 파일 변경 상태 확인git status상태 및 스테이징
git add변경되거나 추가된 파일을 스테이징 영역(추적 대상)에 추가 git add . 또는 git add <특정 파일명>상태 및 스테이징
git rm파일을 삭제하고 해당 삭제 상태를 스테이징 영역에 추가git rm <파일명>상태 및 스테이징
git restore워킹 트리에서 변경된 파일을 수정 이전 상태로 복원git restore <파일명>상태 및 스테이징
git clean추적되지 않는(untracked) 임시 및 불필요 파일 삭제git clean -fd상태 및 스테이징
git commit스테이징된 변경 사항을 로컬 저장소에 하나의 버전으로 기록git commit -m "요약메세지”저장
git commit --amend직전 커밋의 메시지를 변경하거나 누락된 변경 사항을 추가git commit --amend -m "수정 메세지”저장
git tag중요한 커밋(예: 릴리즈 버전 등)에 찾기 쉽도록 태그 부여git tag v1.0.0저장
git diff커밋 간, 브랜치 간, 또는 스테이징 전후의 상세 코드 변경 내역 비교git diff --staged이력 및 비교
git branch로컬 브랜치 목록 확인, 생성, 또는 삭제git branch -d <브랜치명>브렌치
git show특정 커밋에서 발생한 구체적인 변경 사항과 세부 정보 확인git show <커밋해시>이력 및 비교
git blame특정 파일의 라인별로 마지막 수정자와 커밋 정보 확인git blame <파일명>이력 및 비교
git revert특정 커밋의 변경 사항을 취소하는 새로운 커밋을 생성 (이력 보존)git revert <커밋해시>작업 취소 및 임시저장
git checkout특정 브랜치로 작업 환경 이동 또는 파일 복원git checkout -b <새브랜치명>브렌치
git reset특정 커밋 상태로 되돌리며, 이후의 커밋 이력을 삭제git reset --hard HEAD^작업 취소 및 임시저장
git stash작업 중인 내용을 임시로 저장하고 워킹 트리를 깨끗하게 비움git stash save "메시지”작업 취소 및 임시저장
git cherry-pick다른 브랜치에 있는 특정 커밋 하나만 선택하여 현재 브랜치에 적용git cherry-pick <커밋해시>병합 및 통합
git switch특정 브랜치로 이동 (checkout의 이동 기능 대체용)git switch -c <새브랜치명>브렌치
git stash pop임시 저장된 가장 최근 작업을 불러오면서 저장 목록에서 삭제git stash pop작업 취소 및 임시저장
git remote연결된 원격 저장소 목록 확인 및 주소 추가/삭제git remote add origin <주소 혹은 브렌치명등>원격 저장소
git merge다른 브랜치의 변경 이력을 현재 작업 중인 브랜치에 병합git merge <대상브랜치>병합 및 통합
git push로컬 저장소의 커밋 이력을 원격 저장소로 업로드git push origin <브렌치면>원격 저장소
git fetch원격 저장소의 최신 이력을 로컬로 가져오기 (로컬 코드와 병합 X)git fetch origin원격 저장소
git rebase커밋 트리를 깔끔하게 정리하기 위해 현재 브랜치의 기준점을 변경git rebase <대상브랜치>병합 및 통합
git pull원격 저장소의 변경 사항을 가져와 로컬 브랜치에 즉시 병합git pull origin main원격 저장소
git log현재 브랜치의 커밋 히스토리(기록) 상세 조회git log --oneline --graph이력 및 비교
