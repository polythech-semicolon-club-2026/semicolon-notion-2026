7차 정기 과제에 대한 후속 과제 — 포트폴리오 및 발표 준비

추가 작업 내용

1. 개인 프로필 페이지에 프로젝트 추가

제작한 챗봇을 기존 개인 프로필 페이지(포트폴리오)에 추가

2. PPT 발표 자료 제작

다음 내용을 중심으로 발표 준비

  • 프로젝트 소개
  • 개발 목적
  • 사용 기술 스택
  • 전체 구조
  • AI 연결 방식
  • 프론트 ↔ 백엔드 통신 방식
  • API 처리 흐름
  • 주요 기능
  • 구현 과정
  • 개발 중 문제 및 해결 과정
  • 느낀 점 및 향후 개선 방향

발표 방향

“어떤 챗봇을 개발하고자 하였고 어떠한 로직으로 개발했는지”를 설명하는 형태로 준비

예시:

  • 사용자 입력 처리 방식
  • API 요청/응답 흐름
  • 상태 관리 방식
  • 프롬프트 설계 방식
  • 서버 연결 구조
  • 실시간 통신 여부(WebSocket 등)

제출 일정

PPT 제출 마감

  • 6월 1일 (월) 오후 12시 전까지 업로드

추가 사항

석현이는 기존 포트폴리오 초안을 제작,

앞으로 프로젝트를 계속 추가할 수 있는 형태로 구성 추천.

형식은 자유

예시:

  • PPT나 웹사이트 등 한 페이지씩 확장 가능한 포트폴리오
  • 프로젝트별 기술 스택 / 역할 / 결과 정리

발표 시에도 해당 포트폴리오를 활용하여

프로젝트 소개 및 기술 공유 형태로 진행 가능하도록.
