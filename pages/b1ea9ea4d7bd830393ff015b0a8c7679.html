[과제] C언어 기초: 조건문을 활용한 수 비교 프로그램

1. 과제 목표

  • scanf를 통한 데이터 입력 방법 숙달
  • for문을 사용하여 1부터 입력받은 수(n)까지 출력하는 반복 제어 이해
  • if-else문을 활용한 크기 비교 논리 구현

2. 문제 설명
사용자로부터 정수 n을 입력받습니다. 프로그램은 먼저 1부터 n까지의 숫자를 한 줄로 차례대로 출력한 후, 입력받은 n이 5를 기준으로 큰지, 작은지, 혹은 같은지 판별하여 메시지를 출력해야 합니다.

3. 세부 요구 사항

  • 입력: scanf를 사용하여 정수 하나를 입력받을 것.
  • 반복 출력: for문을 사용하여 1부터 사용자가 입력한 숫자 n까지 공백을 두고 출력할 것.
  • 조건 판별: if-else if-else 구조를 사용하여 n과 5를 비교할 것.
    • n > 5: "n은 5보다 큰 수 입니다.”
    • n < 5: "n은 5보다 작은 수 입니다.”
    • n = 5: "5와 같은 수 입니다.”

4. 실행 결과 예시 (n = 3 입력 시)

정수를 입력하세요: 3
1 2 3 (for문으로 출력된 결과)
3은(는) 5보다 작은 수 입니다.
