하위 작업 2 : GitHub Pages 배포

: GitHub Pages 를 통해 io 배포를 실시합니다. (자세한 작업 단계는 개인적으로 학습해보시기 바랍니다.)

  1. 소스 코드 복제 후 개인 레포짓토리 생성 : 모든 하위 페이지 작업이 완료된 main 브렌치 레포짓토리를 다운로드 받아 저장 후, 개인 레포짓토리를 생성하고 저장한 소스코드들을 push 합니다.
  1. 저장소 설정 (Settings): GitHub 저장소 상단 메뉴의 Settings 탭으로 이동합니다.
  1. Pages 메뉴 접속: 왼쪽 사이드바에서 Pages를 클릭합니다.
  1. Build and deployment 설정:
  • Source: 'Deploy from a branch' 선택
  • Branch: 'main' (혹은 배포용 브랜치)와 '/(root)' 폴더를 선택 후 Save를 누릅니다.
  1. 배포 확인: 약 1~3분 후 상단에 https://사용자이름.github.io/저장소이름/ 형태의 URL이 생성됩니다.

하위 작업 3 : Vercel 배포

: Vercel은 GitHub와 연동되어 푸시할 때마다 자동으로 배포를 수행하며, 설정이 매우 간편하고 무료로 사용 가능하여 많이 쓰이는 배포 사이트입니다.
(자세한 작업 단계는 개인적으로 학습해보시기 바랍니다.)

  1. Vercel 로그인: Vercel 공식 사이트에 접속하여 GitHub 계정으로 로그인합니다.
  1. 새 프로젝트 추가: Add New... 버튼을 누르고 Project를 선택합니다.
  1. 저장소 가져오기 (Import): 배포할 팀 프로젝트 저장소를 찾아 Import 버튼을 누릅니다.
  1. 프로젝트 설정:
    • Framework Preset: 순수 HTML/CSS/JS라면 'Other'로 자동 감지됩니다.
    • Root Directory: 프로젝트 최상단에 index.html이 있다면 그대로 둡니다.
  1. Deploy 실행: 하단의 Deploy 버튼을 클릭합니다.
  1. 결과 확인: 배포가 완료되면 고유한 .vercel.app 도메인이 할당되며, 실시간으로 배포된 웹사이트를 확인할 수 있습니다.
