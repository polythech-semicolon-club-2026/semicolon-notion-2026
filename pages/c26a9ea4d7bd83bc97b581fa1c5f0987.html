작업 설명

C언어로 간단한 사칙 연산 계산기를 제작합니다. calculator.c 파일 내에서 나머지 연산 기능을 담당하는 부분을 완성해 주세요. 각자 할당된 이슈에 맞는 번호를 확인하고, 아래 규칙에 맞춰 main브렌치에서 작업할 브렌치를 파생하여 생성 후 작업해주세요.

- 브랜치명: feature/이슈번호/기능 (예: 이슈 번호가 1번이면 feature/1/add)

- 작업 완료 후 원본 저장소로 Pull Request (PR) 요청 : push하자마자 깃허브에 들어가
Pull requests' 탭으로 들어가 'New pull request'를 누른 뒤, base를 main으로, compare를 본인의 feature/... 브랜치로 맞추시면 됩니다. 자세한 방법은 AI나 포털 참고하세요.

‼️주의‼️

pr 보내시고 반드시 단톡에 알려주셔야합니다. pr 보내주신거 merge 하면 제가 merge 했다고 또 단톡에 알려드릴테니, pull 잊지 마세요.
