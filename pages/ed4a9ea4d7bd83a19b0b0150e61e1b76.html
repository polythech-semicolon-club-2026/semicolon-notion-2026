회의록4차 정기 미팅

과제 주제: 확장 가능한 개인 웹사이트 기획 및 기초 프론트엔드 개발

1. 과제 내용

  • 아이디어 구체화: 본인의 관심사, 진로, 또는 해결하고 싶은 문제 등을 바탕으로 개인 웹사이트의 주제를 선정합니다. (예: 개인 포트폴리오, 일정 관리 플래너, 취미 소개 블로그, 스터디 자료 공유 사이트 등)
  • 개발 문서 작성 (Markdown): 선정된 아이디어를 바탕으로 웹사이트의 목적, 주요 기능, 페이지 구조를 마크다운(.md) 형식의 문서로 작성합니다.

2. 과제 제출 규격

  • 작성한 Markdown 기획 문서 (파일명: README.md)
  • 위 파일을 본인의 GitHub 저장소(Repository)에 업로드해 레포짓토리 주소로 제출해주세요. (레포짓토리는 해당 프로젝트용으로 신규 생성 바라며 포폴로 활용할 수 있도록 가능한 git 브렌치 전략과 컨벤션을 적용해 보시길 바랍니다.. )

3. 참고사항 (프로젝트 장기 로드맵)

본 과제는 단발성으로 끝나는 것이 아니라, 졸업 전까지 지속적으로 발전시킬 장기 프로젝트의 첫 단계입니다.아마도 민교수님 시험 대체 과제로 계속 사용될 것으로 예상됩니다. (저도 작년 선배들도 그랬음… 이번에 변화구가 와서 아니게 된다면 유감…. ) 따라서 향후 확장을 고려하여 기획해야 합니다.

  • 1학년 1학기 (현재): 아이디어 기획 및 HTML/CSS 기반 정적 웹페이지 제작 (GitHub Pages 배포 추천하니 GitHub Pages 배포하려면 어떤 구조로 기획해야하는지 찾아보시기 바랍니다.)
  • 1학년 1학기 기말: JavaScript를 도입하여 동적인 인터랙션 및 화면 제어 기능 추가
  • 1학년 2학기: 기존 코드를 React 기반의 싱글 페이지 애플리케이션(SPA) 구조로 변환
  • 2학년: Spring Boot를 활용한 백엔드 구축 및 데이터베이스 연동, 최종적으로 실제 서비스 가능한 형태의 웹 애플리케이션도 추가 할 것으로 예상됨

4. 개발 문서 작성 예시

# 웹사이트 기획 및 개발 문서 (README.md)

## 1. 프로젝트 개요
- 프로젝트명: 통합 학습 및 일정 관리 대시보드
- 목적: 개인의 학습 진행률, 자격증 취득 일정, 스터디 모임 등을 하나의 웹페이지에서 체계적으로 기록하고 관리합니다.
- 대상 사용자: 자기주도적 학습을 진행하는 학생 및 취업 준비생

## 2. 기술 스택 (Tech Stack)
- Frontend: HTML5, CSS3
- Version Control: Git, GitHub
- Deployment: GitHub Pages
- Design Tool: Figma 또는 화면 설계 스케치

## 3. 핵심 기능 요구사항 명세
웹사이트에서 제공할 주요 기능을 정의합니다.

- 네비게이션: 모든 페이지에서 공통 상단 메뉴를 통해 다른 페이지로 이동이 가능해야 합니다.
- 대시보드 (메인): 금주 주요 일정 및 학습 진행률을 요약하여 시각적으로 표시합니다.
- 일정 관리: 월간 달력 형태의 화면을 제공하고 일정을 기입할 수 있는 표(Table) 구조를 구성합니다.
- 자료실: 학습 자료 링크 및 요약본을 목록 형태로 제공합니다.

## 4. 디렉토리 구조 및 웹페이지 표준
프로젝트의 파일 및 폴더 구조를 정의합니다. 향후 유지보수와 확장을 위해 자원을 용도별로 명확히 분리합니다.

+-- index.html (웹사이트 접속 시 최초로 노출되는 메인 대시보드 화면)
+-- schedule.html (일정 관리 화면)
+-- resources.html (자료실 화면)
+-- css/
|   +-- reset.css (브라우저 간 기본 스타일 차이를 없애는 초기화 파일)
|   +-- style.css (웹사이트 전체에 적용되는 공통 디자인 및 레이아웃 파일)
+-- images/
|   +-- logo.png (웹사이트 좌측 상단에 노출될 로고 이미지)
+-- README.md (현재 읽고 있는 프로젝트 기획 및 개발 문서)

## 5. 화면 설계 (UI/UX 구조)
각 페이지의 대략적인 화면 구성을 정의합니다.

- Header 영역: 좌측 상단 로고 이미지, 우측 상단 네비게이션 메뉴 (Home, Schedule, Resources)
- Main Content 영역:
  - 좌측 패널: 사용자 프로필 사진 및 간단한 자기소개
  - 중앙 패널: 핵심 콘텐츠 영역 (일정표, 게시글 목록 등)
- Footer 영역: 하단 저작권 명시 및 이메일 연락처

## 6. 버전 관리 및 협업 규칙 (Git Commit Convention)
체계적인 소스 코드 관리를 위해 코드를 저장(Commit)할 때 아래의 메시지 규칙을 준수합니다.

- feat: 새로운 기능 추가 (예: feat: 메인 페이지 HTML 뼈대 작성)
- fix: 버그 또는 화면 깨짐 오류 수정
- style: 코드 포맷팅, CSS 스타일 변경 및 UI 수정
- docs: README.md 등 문서 작성 및 수정
